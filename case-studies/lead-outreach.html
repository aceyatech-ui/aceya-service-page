Case Study

Cold Email Outreach Workflow

n8n Gmail Google Sheets Telegram APIs

Project type: Independent build

01. Problem

Manual outreach at scale was slow and replies were easy to miss.

Sending personalised emails to multiple leads required repetitive copy-pasting and manual tracking. There was no centralised source of truth, and monitoring replies meant repeatedly checking the inbox.

02. Objective

Build an automated outreach system that sends personalised emails and alerts instantly when someone replies.

The system was designed to handle personalisation, controlled sending, status tracking, and reply monitoring while keeping the lead data inside a single Google Sheet.

03. Architecture

Two workflows, one source of truth.

The system uses two separate n8n workflows. Both interact with the same Google Sheet so outreach status and reply monitoring stay connected.

SENDING WORKFLOW
→ Manual Trigger
→ Google Sheets: Get Rows
→ Split in Batches
→ IF: Skip already sent
→ Format personalised message
→ Subject mapping
→ Gmail: Send
→ Wait 60 seconds
→ Google Sheets: Update status
REPLY MONITOR
→ Schedule Trigger: Every 5 minutes
→ Google Sheets: Get Rows
→ Build Gmail search query
→ Gmail: Search replies
→ IF: Replies exist
→ Split in Batches
→ Format Telegram notification
→ Telegram: Send alert

05. Implementation

What was built.

  • Google Sheets as the source of truth for leads, personalisation data, and outreach status.
  • A controlled sending workflow with a 60-second delay between emails.
  • Automatic status tracking to prevent duplicate sends.
  • A reply-monitoring workflow running every five minutes.
  • Telegram notifications when replies are detected.
06. Tradeoffs

Key decisions and compromises.

  • 60-second delay — slows bulk sending but provides controlled pacing.
  • Gmail instead of dedicated SMTP — simpler and cheaper for the demonstration, while dedicated infrastructure would provide more control at higher volume.
  • Manual sending trigger — keeps the final decision to launch a campaign under human control.
  • Automated reply monitoring — monitoring runs independently so replies do not depend on someone constantly checking the inbox.
07. Result

A working system for the full outreach pipeline.

The workflow can send personalised outreach from structured lead data, record which leads have been contacted, and monitor the inbox for replies.

Reply notifications are delivered through Telegram, reducing the need to manually monitor the inbox.

The system is currently being used as a demonstration of automation capability.

08. What I Learned
  • Google Sheets can work effectively as a lightweight database for small automation systems.
  • Sending controls and rate limits need to be considered when automating email workflows.
  • Separating sending from reply monitoring makes the system easier to control and reason about.
  • Real-time notifications make automated workflows considerably more useful in practice.
