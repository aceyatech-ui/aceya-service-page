Case Study

Cold Email Outreach Workflow

n8n Gmail Google Sheets Telegram APIs

Project type: Independent build

01. Problem

Manual outreach at scale was slow and replies were easy to miss.

Sending personalised emails to hundreds of leads required manual copy-pasting. There was no centralised source of truth and no way to track replies without constantly refreshing the inbox.

02. Objective

Build a fully automated outreach system that sends personalised emails and alerts instantly when someone replies.

The system should handle personalisation, spam protection, status tracking, and reply monitoring — all from a single Google Sheet.

03. Architecture

Two workflows, one source of truth

The system consists of two workflows that share the same Google Sheet as the source of truth.

SENDING WORKFLOW
→ Manual Trigger
→ Google Sheets (Get Rows)
→ Split in Batches
→ IF (Skip sent)
→ Code Node (Format message)
→ Code Node (Subject mapping)
→ Gmail (Send)
→ Wait 60 seconds
→ Google Sheets (Update status)
REPLY MONITOR
→ Schedule Trigger (5 min)
→ Google Sheets (Get Rows)
→ Code Node (Build query)
→ Gmail (Search replies)
→ IF (Replies exist)
→ Split in Batches
→ Code Node (Format Telegram)
→ Telegram (Alert)

05. Implementation

What was built

  • Google Sheets as the source of truth (leads, status, personalisation)
  • Sending workflow with 60-second delay for spam protection
  • Reply monitoring workflow running every 5 minutes
  • Telegram alerts for instant reply notifications
  • Automatic status tracking to prevent duplicate sends
06. Tradeoffs

Key decisions and compromises

  • 60-second delay — protects against spam flags but slows down bulk sending
  • Gmail vs SMTP — Gmail is free but rate-limited; dedicated SMTP would be faster but cost more
  • Manual trigger vs schedule — sending is manual for control; monitoring is fully automated
07. Result

A working system that handles the full outreach pipeline.

The system sends personalised emails with a single click, tracks sent status, and alerts you within 5 minutes of any reply.

The system is currently being used as a demonstration of capability.

08. What I Learned
  • Google Sheets is surprisingly effective as a lightweight database for automation
  • Rate limiting and delays are essential for email deliverability
  • Telegram alerts are extremely useful for real-time notifications
